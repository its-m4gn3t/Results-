AI-Powered Crime & Cybercrime Reporting System

Built for Nepal Police Hackathon

Transforming citizen reports into structured police intelligence using AI.

VISION

“A system where every citizen can report incidents instantly using natural language, and police receive structured, actionable intelligence in real-time.”

🚨 Problem Statement (Nepal Context)

Slow Reporting System

Citizens must visit stations physically or fill complex forms.

Underreporting

Fear, confusion, and lack of accessibility reduce reporting rates.

Cybercrime Growth

OTP scams, fake jobs, phishing attacks increasing rapidly.

No Unified System

Physical + cyber crimes are handled in separate disconnected systems.

💡 Proposed Solution

We introduce an AI-powered unified reporting system that:

  • Understands natural language input
  • Automatically detects crime type & severity
  • Captures GPS location & metadata
  • Generates structured police reports
  • Forwards cases to dashboard instantly

⚙️ System Architecture

User Input → AI Engine → Classification Layer → Database → Police Dashboard → Action

Frontend

React Native (Expo Mobile App)

Backend

FastAPI (Python REST API)

AI Layer

LLM-based classification + rule engine

Database

MongoDB (incident storage)

🔥 Core Features

💬 AI Chat Reporting

Users describe incidents naturally like: “Someone stole my phone”

🚨 Emergency Mode

Instant GPS-based panic alert for critical situations

🧠 Scam Detection

Detects OTP fraud, phishing, fake job offers automatically

📍 Smart Location Tagging

Automatically attaches GPS coordinates to reports

📊 Expected Impact

Faster Response

Reduces reporting time from hours → seconds

Better Policing

Structured data improves investigation efficiency

Cyber Safety

Reduces scam victimization through early warnings

Citizen Trust

Simple reporting increases participation
